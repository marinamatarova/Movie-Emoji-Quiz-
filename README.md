🎬 Movie Emoji Quiz – Угадай фильм по эмодзи 
Увлекательная игра-викторина, где нужно угадать название фильма по набору эмодзи.
Тренируйте память, ассоциативное мышление и знание кинематографа!
Реализована на 7 языках программирования с единым интерфейсом, уровнями сложности, подсказками и таблицей рекордов.

🚀 Возможности
Словарь фильмов – более 50 популярных фильмов с соответствующими эмодзи-подсказками.

Три уровня сложности:

Лёгкий – известные фильмы, 60 секунд на ответ.

Средний – менее очевидные фильмы, 45 секунд.

Сложный – культовые фильмы с неочевидными эмодзи, 30 секунд.

Подсказки – показать количество букв в названии, первую букву или год выхода (в зависимости от уровня).

Система очков – чем быстрее ответ, тем больше очков.

Статистика – количество угаданных фильмов, пропусков, общий счёт.

Сохранение рекордов – лучший результат сохраняется в файл.

Цветной вывод – эмодзи, сообщения, таймер и счёт выделены цветами.

Интерактивность – ввод ответа с клавиатуры, подсказки, пропуск.

📖 Использование
Синтаксис (единый для всех версий):

bash
<команда> [уровень] [опции]
Уровни
easy – лёгкий (по умолчанию).

medium – средний.

hard – сложный.

Опции
Опция	Описание
-s, --stats	Показать статистику и выйти
-r, --reset	Сбросить рекорды
-h, --help	Справка
Управление
Введите название фильма и нажмите Enter.

? – подсказка (показывает первую букву).

pass – пропустить фильм.

quit – выход.

Примеры
bash
# Лёгкий уровень
python movie_emoji.py

# Средний уровень
python movie_emoji.py medium

# Показать статистику
python movie_emoji.py -s

🧠 Логика игры
Выбор фильма – случайный фильм из словаря в зависимости от уровня.

Отображение эмодзи – игрок видит набор эмодзи, символизирующих фильм.

Таймер – ограниченное время на ответ.

Ввод – игрок вводит название фильма.

Проверка – если название совпадает (без учёта регистра), начисляются очки.

Подсказка – показывает первую букву названия или количество букв.

Пропуск – можно пропустить фильм (без штрафа, но без очков).

Счёт – очки начисляются в зависимости от времени ответа.

Игра – продолжается до тех пор, пока игрок не решит выйти или не будет достигнут лимит фильмов (по умолчанию 10).

✨ Дополнительные фичи
Автосохранение – статистика сохраняется в файл ~/.movie_emoji_stats.json.

Цветной вывод – эмодзи и сообщения выделены цветами.

Гибкий словарь – можно легко расширять фильмы и эмодзи в коде.
